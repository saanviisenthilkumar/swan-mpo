# Third-party notices

SWAN-MPO can interoperate with the following independently licensed projects. Consult each project's distributed license for authoritative terms.

- AutoDock Vina — molecular docking executable used for optional reference-ligand redocking.
- RDKit — cheminformatics toolkit used in the audited manuscript environment and upstream workflows.
- Open Babel — chemical file conversion/preparation toolkit used in the audited manuscript environment and upstream workflows.
- NumPy — numerical dependency of the locked model.
- NetworkX — graph-isomorphism dependency used by the built-in symmetry-aware fixed-frame RMSD path.
- pytest — development/test dependency.

No third-party receptor or ligand structure file is intentionally bundled in this release candidate.
